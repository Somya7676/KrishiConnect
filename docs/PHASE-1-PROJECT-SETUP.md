# KrishiConnect – Phase 1: Project Setup

## Project Overview
KrishiConnect is a Farmer Marketplace and Community Portal designed to connect farmers, buyers, sellers, and agricultural vendors through a digital platform.

## Phase 1: Project Setup

### Work Completed

1. Created the main KrishiConnect project folder and organized the project structure.
2. Initialized the frontend using React.js and Vite.
3. Set up the backend using Node.js and Express.js.
4. Installed the required frontend and backend dependencies.
5. Created backend folders for configuration, models, controllers, routes, middleware, and uploads.
6. Created a MongoDB Atlas cluster named KrishiConnect-Cluster.
7. Created database access credentials and configured the MongoDB connection through environment variables.
8. Connected the backend application to MongoDB Atlas successfully.
9. Created initial API endpoints and verified that the backend server runs successfully.
10. Started the React frontend and verified the initial welcome page.
11. Configured Git and `.gitignore` to exclude sensitive environment files and dependency folders.
